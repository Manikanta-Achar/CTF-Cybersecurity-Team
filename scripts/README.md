## Completed Scripts

### 1. Caesar Cipher Tool

**Description:** A Python tool that encrypts and decrypts messages using the Caesar Cipher technique.

**Example:**
- Original text: HELLO
- Shift value: 3
- Encrypted text: KHOOR

**Features:**
- Encrypt messages
- Decrypt messages
- Supports uppercase and lowercase letters
- Preserves spaces and special characters

**Technology:** Python 3

**Run the script:**
```bash
python caesar_cipher.py
```

**Learning Outcomes:**
- Basic cryptography
- Python strings and loops
- ASCII character manipulation

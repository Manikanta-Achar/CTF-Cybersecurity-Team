# Learning Resources

Curated starting points for learning cybersecurity fundamentals and practicing in permitted environments. Always follow each platform's rules and stay within the scope of authorized labs.

## Practice platforms

- [picoCTF](https://picoctf.org/) — beginner-friendly CTF challenges and learning material.
- [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) — command-line and Linux fundamentals.
- [TryHackMe](https://tryhackme.com/) — guided cybersecurity learning rooms and labs.

## Reference material

- [Python documentation](https://docs.python.org/3/) — language and standard-library reference.
- [Python `hashlib`](https://docs.python.org/3/library/hashlib.html) — hash algorithms available in Python.
- [Python `ipaddress`](https://docs.python.org/3/library/ipaddress.html) — IP address parsing and properties.
- [Python `socket`](https://docs.python.org/3/library/socket.html) — networking APIs including system name resolution.
- [OWASP Top 10](https://owasp.org/www-project-top-ten/) — awareness document for common web application risks.
- [Wireshark documentation](https://www.wireshark.org/docs/) — documentation for network protocol analysis.

## Suggested study areas

Cryptography basics, web security, digital forensics, networking, OSINT using public and permitted information, and Python programming. Use the repository's [practice writeup templates](../writeups/README.md) to record methods, evidence, and learning from genuine exercises.
